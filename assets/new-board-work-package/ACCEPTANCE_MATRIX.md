| Interface | Required | Demo unit | Contract | Build | Ready for board | Board result | Waiver | Release/evidence |
|---|---:|---|---|---|---|---|---|---|
| `<interface>` | YES | `<demo-unit>` | `OPEN` | `NOT_RUN` | NO | `NOT_RUN` | NONE | |

Allowed board-result values include `BOARD_PASS`, `FPGA_READY_HARDWARE_BLOCKED`, `FAILED_FPGA`, `NOT_RUN`, and an explicitly documented waiver. Build success is not a board pass.
